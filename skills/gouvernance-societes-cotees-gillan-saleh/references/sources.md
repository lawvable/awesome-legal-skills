# Sources — où obtenir les documents du corpus

Ce skill **n'inclut pas** les documents sources (droit d'auteur) : il en restitue des index analytiques. Pour exploiter pleinement le skill, ou pour vérifier une citation à sa page, il faut consulter les documents originaux auprès de leurs éditeurs. Ce guide donne les liens officiels.

> Les documents ci-dessous demeurent la propriété de leurs éditeurs et ne sont pas couverts par la licence du skill (voir `NOTICES.md`). Les URL directes vers des PDF peuvent changer au gré des réorganisations de site ; en cas de lien rompu, partir de la page officielle de l'éditeur indiquée. Liens vérifiés en juin 2026.

---

## 1. AMF — Autorité des marchés financiers (régulateur)

**Rapports annuels sur le gouvernement d'entreprise et la rémunération des dirigeants des sociétés cotées (exercices 2020 à 2025).** Chaque millésime a sa page dédiée sur le site de l'AMF, qui héberge le PDF :
- Portail des publications : https://www.amf-france.org/fr/actualites-publications/publications
- Schéma de page par millésime (exemples vérifiés) :
  - Rapport 2020 : https://www.amf-france.org/en/news-publications/publications/reports-research-and-analysis/2020-report-corporate-governance-and-executive-compensation-listed-companies
  - Rapport 2021 : page « 2021-report-corporate-governance-and-executive-compensation-listed-companies » (même schéma).
  - Rapport 2025 : https://www.amf-france.org/en/forms-and-declarations/listed-companies-and-corporate-financing/2025-report-corporate-governance-and-executive-compensation-listed-companies
  - Pour 2022, 2023, 2024 : même schéma d'URL en remplaçant l'année ; ou recherche « rapport [année] gouvernement d'entreprise » sur amf-france.org.

**Guide d'élaboration du document d'enregistrement universel — position-recommandation DOC-2021-02.** Rubrique doctrine de l'AMF (rechercher « DOC-2021-02 ») : https://www.amf-france.org/fr/reglementation/doctrine

**Doctrine AMF sur la durabilité (DPEF/CSRD), bilan 2024.** Rubrique publications / doctrine de l'AMF (rechercher « durabilité CSRD bilan »).

**Recommandation DOC-2025-08 — arrêté des comptes 2025 :**
https://www.amf-france.org/sites/institutionnel/files/private/2025-10/amf-recommandation-doc-2025-08-arrete-des-comptes-2025.pdf

**Étude CSRD « Corporate Sustainability Reporting: The Way Forward » (2025) :**
https://www.amf-france.org/sites/institutionnel/files/private/2025-10/amf_study_csrd_reporting_the_way_forward_2025.pdf

## 3. Code AFEP-MEDEF (soft law privée)

**Code de gouvernement d'entreprise des sociétés cotées, édition décembre 2022.** Publié par l'AFEP et le MEDEF, sur leurs sites officiels :
- AFEP : https://afep.com (rubrique gouvernance / Code AFEP-MEDEF)
- MEDEF : https://www.medef.com

*Le skill ne reproduit pas le texte du Code : il fournit une table de références croisées par article (voir `references/code-afep-medef-references.md`). Le texte doit être consulté sur les sites ci-dessus.*
