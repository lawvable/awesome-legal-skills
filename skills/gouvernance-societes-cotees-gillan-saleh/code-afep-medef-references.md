# Table des références — Code AFEP-MEDEF décembre 2022

## Métadonnées

**Référence complète** : *Code de gouvernement d'entreprise des sociétés cotées*, AFEP-MEDEF, **révision de décembre 2022**, 49 pages.

**Émetteur** : **AFEP** (Association Française des Entreprises Privées) et **MEDEF** (Mouvement des Entreprises de France). Co-éditeurs du Code depuis 1995.

**Nature juridique** : **soft law**. Le Code est un référentiel privé. Sa qualification en droit français découle de l'article L. 22-10-10 du Code de commerce : un émetteur peut désigner « volontairement » un code de gouvernement d'entreprise comme code de référence et appliquer la règle « se conformer ou expliquer » (alinéa 3° de l'article L. 22-10-10).

**Sourçage de la nature juridique** : Préambule du Code, p. 1. Le Code y précise que l'ensemble de recommandations qu'il constitue peut être désigné par les sociétés cotées comme code de référence en application des articles L. 22-10-10 et L. 22-10-20 du code de commerce (texte au Code, préambule, p. 1).

**Règle « appliquer ou expliquer »** : expression française officielle utilisée par le Code AFEP-MEDEF lui-même (article 28, p. 31), traduction du « comply or explain » européen. Portée (article 28.1, p. 31) : les sociétés cotées se référant au Code rendent compte de manière précise, dans leur rapport sur le gouvernement d'entreprise, de l'application des recommandations et fournissent une explication lorsqu'elles en écartent une (texte au Code, art. 28.1, p. 31).

**Rôle du HCGE** : article 28.2 du Code (p. 31). Le HCGE n'est pas un régulateur ; il n'a pas de pouvoir de sanction au sens du droit administratif. Il peut recourir au **« name and shame »** (cf. Guide d'application HCGE mars 2024, p. 3).

**Reproduction du contenu du Code** : le texte des recommandations du Code AFEP-MEDEF est protégé par le droit d'auteur AFEP-MEDEF. Le présent fichier reproduit **uniquement les titres des articles** (structure du document, élément factuel d'identification) et les **références aux paragraphes** (§ X.Y), sans le texte intégral des recommandations. Pour le contenu des recommandations, se reporter au PDF dans `/mnt/project/Code_AFEP_MEDEF_decembre_2022.pdf`.
