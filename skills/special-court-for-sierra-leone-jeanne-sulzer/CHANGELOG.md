### Skill scope at v1.0.0
- Covers SCSL operations (2002-2013) and RSCSL ongoing functions (since 2 December 2013)
- Encodes the same verification-first methodology as the other skills in this repository
- Specifically equips the user to handle the SCSL's landmark holdings on child soldiers, forced marriage, head-of-state immunity, and aiding-and-abetting
- Maps the four principal cases (Taylor, AFRC, CDF, RUF) with full case numbers, phase suffixes, and key judgment dates

### Known limitations
- SCSL procedural decisions are voluminous; the skill maps principal landmark holdings only
- The aiding-and-abetting standard "tension" between SCSL (Taylor Appeal 2013) and ICTY (Perišić 2013 / Šainović 2014) is flagged but not resolved — the doctrinal debate is left to the user
- Sierra Leone Truth and Reconciliation Commission materials are not in scope of this skill (the TRC is a separate, non-judicial institution)
