# Impropriétés et vocabulaire juridiques

Erreurs de vocabulaire propres au droit français. La distinction *stipuler/disposer* est la seule traitée **automatiquement** par le script (sous condition de sujet) ; les autres relèvent du **jugement** car elles dépendent du sens.

## 1. Stipuler / disposer — *déterministe (script, sous condition)*

- **Disposer** (ou *prévoir, énoncer, édicter*) : pour la **loi, le règlement, l'article, le décret, l'ordonnance, le code, le texte**.
  - ✅ « L'article 1240 du Code civil dispose que… »
- **Stipuler** : réservé aux **conventions** (contrat, accord entre parties).
  - ✅ « Le contrat stipule une clause de non-concurrence. »

Le script ne corrige *stipuler→disposer* que lorsque le **sujet** est un texte normatif (loi, article, décret, règlement, ordonnance, code, alinéa…). Il **ne touche pas** « le contrat stipule » (correct), ni les emplois dont le sujet est ambigu (→ jugement).

Erreurs fréquentes corrigées : « la loi stipule », « l'article 1382 stipule », « le décret stipule » → *dispose*.

## 2. Distinctions à arbitrer au jugement

- **Juridiction / justice** : la *juridiction* est l'organe (tribunal, cour) ; la *justice* est l'institution. « Saisir la juridiction compétente » plutôt que « saisir la justice ».
- **Arrêt / jugement** : *arrêt* = décision d'une cour (Cassation, cour d'appel) ; *jugement* = décision d'un tribunal.
- **Attendu que / considérant que** : *attendu que* devant les juridictions judiciaires ; *considérant que* devant les juridictions administratives.
- **Préjudice / dommage** : le *dommage* est l'atteinte ; le *préjudice* en est la conséquence réparable. À respecter en contexte doctrinal.
- **Prescription / forclusion / déchéance** : extinction du droit par le temps / perte du droit d'agir (délai procédural) / perte-sanction d'un droit.
- **Nullité / inexistence** ; **responsabilité civile / pénale** ; **garde à vue / détention provisoire** ; **avocat / juriste / (ancien) conseil juridique**.
- **Amende / peine / sanction / astreinte / dommages-intérêts** : ne pas confondre la sanction pénale (peine, amende), la mesure civile (astreinte, dommages-intérêts) et le terme générique (sanction).

## 3. Tournures et impropriétés transversales fréquentes en droit

| À éviter | Préférer |
|---|---|
| la loi stipule | la loi dispose (cf. §1) |
| suite à | à la suite de, par suite de, en réponse à |
| au niveau de (hors hiérarchie/géographie) | quant à, concernant, en matière de |
| de par | par, du fait de |
| voire même (pléonasme) | voire |
| au final | en définitive, finalement |
| solutionner | résoudre |
| pallier à | pallier (transitif direct) |
| et/ou | l'un, l'autre ou les deux (reformuler) |
| par contre (registre soutenu) | en revanche |
| nonobstant (ok) | (correct en registre soutenu) |
| second / deuxième | *second* quand il n'y a que deux éléments |
| dommages et intérêts | dommages-intérêts (graphie usuelle) |
| problématique (nom, hors académique) | problème, question |

**Locutions juridiques correctes à ne pas « corriger »** : *en l'espèce, dès lors, partant, il échet, il appert, débouter, faire droit, ester en justice, à l'encontre de, au visa de, par ces motifs*. Les conserver.

## 4. Pléonasmes et impropriétés univoques — *déterministe (script)*

Une seule forme correcte, donc corrigées automatiquement (édition directe) :
- `voire même` → `voire`
- `pallier à` → `pallier` (transitif direct)
- `au jour d'aujourd'hui` → `aujourd'hui`

Les autres (*de par*, *au final*, *solutionner*, *et/ou*, *suite à*…) restent au **jugement** : le choix dépend du contexte.
