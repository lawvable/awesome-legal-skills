# Anglicismes — noyau sûr, contextuel et liste blanche

Trois ensembles. Seul le **noyau sûr** est remplacé automatiquement par le script ; le **contextuel** relève du jugement ; la **liste blanche** est conservée telle quelle.

## 1. Noyau sûr — remplacement automatique (script)

Calques sans homographe français, donc remplaçables sans risque de contresens. Remplacement en **révision Word** (forme : `del` ancien → `ins` nouveau), casse et accord à préserver au mieux.

| Anglicisme | Équivalent |
|---|---|
| digital (sens informatique) | numérique |
| deadline | échéance, date limite |
| feedback | retour |
| brainstorming | remue-méninges |
| benchmark (subst.) | étalonnage, comparatif |
| overview | vue d'ensemble, aperçu |
| checker | vérifier, contrôler |
| forwarder | transmettre, faire suivre |
| switcher | basculer |
| booker | réserver |
| customiser | personnaliser |
| upgrader | mettre à niveau |
| downloader | télécharger |
| uploader | téléverser |
| scheduler | planifier |
| dispatcher | répartir |
| briefer | informer |
| débriefer | faire le point |
| sponsoriser | parrainer |
| canceler | annuler |
| « sur une base régulière » | régulièrement |
| « à date » | à ce jour |

Cette table est **éditable** : ajouter ici tout calque dont on est certain qu'il n'a pas d'autre sens en français.

## 2. Contextuel — jugement requis (NE PAS scripter)

Mots qui **existent en français avec un autre sens** (faux-amis) ou dont le remplacement dépend du contexte. Les corriger seulement après lecture, lorsqu'ils sont employés au sens anglais.

| Forme | Sens anglais fautif | Sens / traitement français |
|---|---|---|
| supporter | endurer ≠ soutenir | « supporter la douleur » est correct ; au sens *soutenir/appuyer* → corriger |
| réaliser | se rendre compte | accomplir ; au sens *comprendre* → « se rendre compte » |
| opportunité | occasion | l'*opportunité* = le caractère opportun ; au sens *occasion* → corriger |
| adresser (un problème) | traiter | *adresser* = envoyer/destiner ; au sens *traiter* → « traiter, prendre en charge » |
| impacter | influer sur | débattu ; préférer « avoir une incidence sur, affecter » |
| éligible | admissible | l'*éligible* peut être élu ; au sens *recevable* → « admissible, recevable » |
| versatile | inconstant | en FR = *changeant* ; au sens *polyvalent* → corriger |
| définitivement | de façon définitive | au sens *assurément* → corriger |
| actuel / actuellement | présent / à présent | au sens *réel / en fait* → « réel / en réalité » |
| large | ample en largeur | au sens *vaste/important* → corriger |
| location | action de louer | au sens *emplacement* → « emplacement, site » |
| éventuel / éventuellement | possible / le cas échéant | au sens *final / finalement* → corriger |
| assumer | endosser | au sens *supposer* → « présumer, supposer » |
| baser sur | — | « se fonder sur, reposer sur » |
| au niveau de | hiérarchie/étage réels | sinon → « quant à, concernant » |
| en termes de | — | varier : « quant à, pour ce qui est de » |

## 3. Liste blanche — termes de la matière, conservés

Termes techniques consacrés, conservés tels quels (validés par l'utilisateur ; **éditable**). Ne jamais les « franciser » d'office.

`M&A`, `common law`, `civil law`, `trust`, `trustee`, `leasing` (équivalent *crédit-bail* mentionnable, non imposé), `holding`, `joint-venture`, `due diligence`, `term sheet`, `covenant`, `escrow`, `closing` (sens M&A), `LBO`, `MBO`, `equity`, `spin-off`, `carve-out`, `compliance` (préférer *conformité* en français soutenu, mais toléré), `soft law`, `hard law`, `class action`, `forum shopping`, `discovery`.

Les locutions **latines** (*ratio decidendi*, *obiter dictum*, *stare decisis*, *amicus curiae*, *a priori*, *in fine*…) ne sont pas des anglicismes : les conserver, en italique.

**Règle de frontière** : un terme de la liste blanche reste anglais ; tout autre anglicisme du noyau sûr est corrigé ; tout terme contextuel est arbitré à la lecture. En cas de doute sur l'appartenance à la matière, conserver et signaler par commentaire plutôt que corriger.
