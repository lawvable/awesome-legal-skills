# Harmonisation orthographique (rectifications de 1990) — *jugement*

Les rectifications de 1990 sont **facultatives** : les deux graphies sont admises. La skill ne tranche pas dans l'absolu — elle **harmonise le document sur sa graphie majoritaire**, comme pour les références (cf. `citations-reflex.md`).

## Procédure

1. Détecter la coexistence des deux graphies dans le document :
   - accent circonflexe i/u : `coût`/`cout`, `paraître`/`paraitre`, `entraîner`/`entrainer`, `maître`/`maitre` ;
   - tréma : `aiguë`/`aigüe`, `ambiguïté`/`ambigüité` ;
   - soudure : `week-end`/`weekend`, `porte-monnaie`/`portemonnaie`, `contre-exemple`/`contrexemple` ;
   - `é`/`è` : `événement`/`évènement`, `réglementaire`/`règlementaire`.
2. Déterminer la graphie **dominante**.
3. Aligner les formes minoritaires sur la dominante, **en révision Word** (entrée de jugement au registre).

Ne jamais imposer la réforme ni l'inverse : seule compte la cohérence interne. En cas d'équilibre ou de doute, ne rien changer et le signaler.
