# Nice Classification — Quick Reference & Relatedness

The Nice Classification (12th ed., used in both US and Canada) groups goods (1-34) and services (35-45). Nice does not control confusion — relatedness does — but the class is the entry point for class-based searching at USPTO and a useful organizing field at CIPO.

## Relatedness pairings (USPTO §2(d) / TMEP 1207.01)

## Canadian relatedness

CIPO applies s. 6(5)(c) (nature of wares/services) and s. 6(5)(d) (nature of trade) without requiring class match. The same pairings above are persuasive in Canada. The **Masterpiece** "casual consumer somewhat in a hurry" test means visual-aural-conceptual similarity dominates over fine class distinctions.

## Tactics for tech / SaaS / AI clients

Default Nice strategy for a software-and-platform brand:

- **Class 9** — downloadable software, mobile applications, downloadable AI models
- **Class 42** — SaaS, PaaS, AI-as-a-service, software development services, hosting
- **Class 35** — if there's a marketplace / online retail component
- **Class 41** — if there's downloadable / streamed educational or media content
- **Class 38** — if there's a real-time communication / messaging core feature

For legal-tech products: 9 + 42 + 45 (legal information services, depending on disclaimer of unauthorized practice).
