# Arbitration Clause Design and Review
## sources.md
## Purpose
This file records the source materials used by the **Arbitration Clause Design and Review** skill.
The purpose of this file is to keep the operational skill clean. The `SKILL.md` tells the assistant what to do. This `sources.md` records where the assistant should look, what materials may be used, and which sources require live verification before use.
# Source-use principles
The skill should distinguish between:
1. live source material;
2. public institutional data;
3. model clause wording;
4. user-provided contract facts;
5. analytical recommendations generated by the skill.
Where a source may change over time, the skill should retrieve or verify the current version at the time of use where possible.
Where a source is used for exact clause wording, the skill should use the current official version and avoid relying on stale stored wording unless the current source cannot be retrieved.
If a source cannot be retrieved, the skill should say so and proceed cautiously.

# 2. Delos model clauses
## Source
Delos model clauses page:
https://delosdr.org/model-clauses/
## Use
Use this source for:
1. Delos arbitration clause;
2. negotiation option before arbitration;
3. arbitration-confidentiality clause;
4. governing-law clause;
5. agreement for submitting existing disputes to Delos arbitration;
6. clause to opt into the Delos Compliance Reinforcement Mechanism.
## Treatment
The skill should retrieve the current wording from the Delos model clauses page where possible.
The Delos arbitration clause, arbitration-confidentiality clause and governing-law clause may be stored in the package and attributed.
Where Delos arbitration is selected, use the Delos arbitration clause as the base.
Where confidentiality is desired and no more appropriate clause is provided, the Delos arbitration-confidentiality clause may be used as neutral companion wording, irrespective of whether the arbitration itself is under the Delos Rules.
Where the contract lacks a governing-law clause, the Delos model governing-law clause may be used as neutral companion wording, irrespective of whether the arbitration itself is under the Delos Rules.
Using the Delos confidentiality or governing-law clause does not make the arbitration a Delos arbitration.
Where Delos materials are used outside Delos arbitration, the output should make clear that they are being used as neutral model wording or reference material, not because Delos arbitration has been selected.
## Governing-law model wording
Current Delos model governing-law wording:
"This contract shall be governed by, and construed in accordance with, the laws of [jurisdiction] disregarding its conflict of laws and jurisdiction provisions."
## Delos confidentiality clause
Current Delos model arbitration-confidentiality wording:
"The parties agree to keep confidential the existence and contents of the arbitration and the written and oral pleadings and all documents produced for or arising from the arbitration, save as may be required by legal or regulatory duty or to protect or pursue a legal right."
Use the Delos confidentiality clause where the user wants confidentiality, or where the context strongly indicates that confidentiality should be addressed and the user accepts inclusion.
Credit may be given concisely:
"The confidentiality wording is based on Delos model wording."
## Delos Compliance Reinforcement Mechanism
Retrieve exact current wording from the Delos model clauses page.
Use only as an optional add-on where the enforcement profile makes it relevant, or where the user asks about enforcement incentives.
Do not force it into ordinary clauses.

# 4. Cost data and calculators
## Arbitration Costs Calculator — preferred consolidated source

The calculator has two public pages:

**Human-facing calculator page** (public reference for user links and manual calculation):
URL: https://virjee-arbitration.com/arbitration-costs-calculator/

**Machine-readable specification page** (machine/runtime source — contains the public data bundle, calculation contract, non-browser calculation algorithm, output schema and examples):
URL: https://virjee-arbitration.com/arbitration-costs-calculator-machine-readable/

This is the preferred calculation source for institutional/administrative and tribunal fee estimates for the five supported institutions: ICC, HKIAC, SIAC, DELOS and Swiss Arbitration Centre (SAC).

Where a runtime can read and apply the machine-readable specification, it should calculate directly using the data bundle and non-browser calculation algorithm. Where it cannot do so reliably, direct the user to the human-facing calculator page with the specific inputs to enter. There is no server-side result endpoint. Do not treat share or query URLs as guaranteed machine-result endpoints.

**What the calculator estimates:** institutional/administrative and tribunal fees.

**What it does not estimate:** total arbitration costs. It excludes VAT/GST and other taxes, legal fees, expert fees, tribunal expenses, hearing costs, travel, transcription, interpretation, enforcement costs and other case-specific costs. Do not describe it as a total-cost or arbitrator-remuneration calculator.

**Supported currencies:** EUR, USD, SGD, HKD, CHF.

**Supported range:** the calculator has a supported amount range. Do not extrapolate beyond it.

## General rule
Cost comparisons should be used only where reliable data is available.

## Cost comparison disclosure requirements
Every cost comparison produced by this skill must state:
- assumed amount in dispute and currency;
- assumed number of arbitrators;
- source type: live calculator run; published fee schedule (edition/date); or stored verified example from examples.md;
- where a stored example is used, note the example reference and that assumptions should be verified before use in negotiations.

If live calculators cannot be accessed, use stored verified example figures from examples.md with their original assumptions, or direct the user to the official calculators and state that live calculation is required. Do not generate new numerical ranges from general knowledge.
Do not present estimates as guarantees.
Use language such as:
1. indicative;
2. approximate;
3. based on available published data;
4. subject to the applicable fee schedule and procedural developments.
## User inputs required
To provide a useful cost comparison, ask for:
1. expected dispute value; or
2. illustrative dispute value; and
3. currency, if relevant.
If the user cannot provide an expected value but contract value is available, the skill may offer to run an illustrative comparison using contract value as the reference amount. Make clear that this is not necessarily the expected claim value.
For regional institution proposal scenarios, the mandatory cost-comparison rule in SKILL.md applies: where contract value or expected dispute value is available, the comparison must appear in the main answer and must not be deferred to optional next steps.

# 5. Duration statistics sources
## General treatment
Duration statistics should be used cautiously.
They are useful for broad comparisons, but they are not directly comparable across institutions unless the methodology is checked. Differences may include:
1. whether duration is measured from filing, constitution of tribunal, transmission of file, or another procedural milestone;
2. whether the dataset includes only cases ending in final awards;
3. whether withdrawn or settled cases are excluded;
4. whether expedited or emergency cases are included;
5. the relevant time period studied;
6. whether the data is mean, median, or both;
7. whether proceedings suspended by party agreement are included.
The skill should not present duration figures as predictions or guarantees.
Use wording such as:
"Based on published duration statistics, and subject to differences in methodology, [institution] reports [figure]. This is not a prediction for any specific case."

## Use in outputs
When providing a duration comparison, the skill should:
1. state the institution;
2. state the reported figure;
3. state the source year or period;
4. identify whether the figure is mean or median;
5. flag material methodology differences;
6. avoid predicting the duration of the user's specific dispute;
7. offer to provide a fuller comparison if the user wants detail.
Example output:
"Published duration statistics are not perfectly comparable, but they are directionally useful. Based on the most recently published ICC statistics (2024), the average duration was 26 months and the median was 22 months for cases concluding by final award; check the ICC statistics page for more recent figures. Based on the most recently published LCIA analysis (2024), the median duration was 20 months; check the LCIA website for more recent figures. SIAC's 2016 study reported a median duration of 11.7 months, but that data is older and should be treated as historical."
# 6. Source hierarchy for drafting
When drafting an arbitration clause, use this hierarchy:
1. User's express instruction.
2. Applicable institutional model clause.
3. Delos model clause where Delos arbitration is selected.
4. UNCITRAL model clause where UNCITRAL ad hoc arbitration is selected.
5. Delos confidentiality clause where confidentiality is desired and no more appropriate wording is provided.
6. Delos governing-law clause where a governing-law clause is needed and no more appropriate wording is provided.
7. Bespoke drafting from first principles, with appropriate caveats.
If user instructions conflict with institutional model wording, preserve the user's commercial objective but explain the drafting risk.
# 7. Source hierarchy for analysis
When analysing or recommending, use this hierarchy:
1. User-provided facts and documents.
2. Current official institutional rules and model clauses.
3. Delos GAP traffic-light table for seat assessment.
4. Official fee schedules and published statistics.
5. Publicly available institutional guidance.
6. The skill's own analytical framework.
7. General arbitration practice, expressed cautiously.
Do not present private or internal commentary as a source.
# 8. Public/private boundary
The following may be used in public outputs:
1. official model clauses;
2. official institutional rules;
3. GAP traffic-light assessments;
4. published fee schedules;
5. official cost calculators;
6. published duration/cost statistics;
7. neutral comparative criteria;
8. user-provided facts.
The following should not appear in public outputs:
1. unsupported claims about institutions;
2. personal views attributed to Hafez Virjee;
3. non-public data not approved for publication.
Public outputs should be criteria-based, neutral and reputationally safe.
# 9. Bias-control sources
When Delos is recommended, the output should identify the criteria supporting the recommendation.
Acceptable criteria include:
1. time discipline;
2. cost predictability;
3. proportionality;
4. access to justice;
5. relationship preservation;
6. settlement incentives;
7. a neutral administered process;
8. suitability for the likely dispute value;
9. user preference for procedural discipline.
When Delos is not recommended, the skill should say so naturally and without defensiveness.
Do not include Delos in a shortlist unless the criteria support it.
Do not describe Delos as "less conventional" unless the user specifically asks about market familiarity.
