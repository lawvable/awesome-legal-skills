# Performance Test (PT) Method

> The CA PT is a **90-minute** closed-universe exercise: you get a **File** (the facts —
> memos, letters, transcripts, documents) and a **Library** (the law — cases, statutes,
> rules), and you produce a lawyering work product. **No outside law is needed or
> wanted** — everything is in the packet. This rewards method over memorization.

## What the PT tests

Not what you know, but whether you can (1) extract relevant facts, (2) read and synthesize
the provided authority, (3) apply law to facts, and (4) produce the requested document in
the requested format and tone. The **task memo** (usually the first document) is the
controlling instruction — it tells you the assignment, the format, and often what to
include or omit.

## The 90-minute clock

| Phase | Time | What you do |
|-------|------|-------------|
| Read the task memo | ~5 min | Identify the work product, audience, format, and any explicit instructions/constraints. |
| Read the Library | ~20 min | Brief each case/statute: rule, holding, key facts. Note how authorities relate (which controls, which distinguishes). |
| Read the File | ~20 min | Pull every relevant fact; note bad facts and gaps. Tie facts to the Library rules as you go. |
| Outline | ~10 min | Structure the document to the requested format; assign facts to each legal point. |
| Write | ~30 min | Draft, applying law to facts under proper headings. |
| Review | ~5 min | Format, headings, every task instruction satisfied. |

Adjust as needed, but **read the task memo first and last.**

## Common work products & their skeletons

**Objective memo (to a supervising attorney)**
- Heading (to/from/re/date) → Question Presented → Brief Answer → Statement of Facts →
  Discussion (issue-by-issue, IRAC, balanced — include weaknesses) → Conclusion.
- Tone: neutral, predictive. Tell the partner what *will* happen, not what you wish.

**Persuasive brief / memorandum of points & authorities**
- Caption → Introduction → Statement of Facts (advocacy-slanted but accurate) → Argument
  (point headings as persuasive assertions, then CRAC) → Conclusion/Prayer.
- Tone: argumentative. Frame law and facts for your client; distinguish adverse authority.

**Demand / opinion / client letter**
- Lay audience: plain language, less citation, clear recommendation and next steps.

**Other tasks** (sometimes): contract or will provisions, discovery plan, closing argument,
will/trust drafting, statute analysis. Match the format the task memo specifies exactly.

## Method that scores

- **Organize around the Library's structure.** If the Library gives a multi-factor test or a
  two-prong rule, make those the headings and march through each with File facts.
- **Use the facts heavily.** Like the essays, application wins. Cite the specific document,
  date, or quote from the File ("the May 3 letter states…").
- **Cite the Library**, not outside law. Use short citations to the provided cases/statutes.
  You don't need perfect Bluebook — you need to show which authority supports each point.
- **Handle bad facts and adverse authority head-on** — distinguish or concede-and-minimize.
  Ignoring them reads as missing them.
- **Follow every instruction in the task memo** (page limits, sections to include, issues to
  skip). Graders check these literally.

## Pitfalls

- Spending too long reading and leaving no time to write — **watch the clock; start writing
  by ~minute 55.**
- Writing a law-school essay instead of the requested document/format.
- Importing outside law (wastes time, sometimes penalized — the universe is closed).
- Burying the recommendation; lead with it where the format calls for it.
- Generic point headings ("Argument I") instead of substantive, fact-specific headings.

## Practice loop

Time yourself at a true 90 minutes with a real released CA PT. Then run the skill's **Grade**
mode on the PT: did you produce the requested format, hit every task-memo instruction, brief
and apply every Library authority, and use specific File facts? Track recurring misses (e.g.,
running out of writing time, thin fact use) and fix the method, not the law.
