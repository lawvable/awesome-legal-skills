# Exam-Day Method — Essays

> How to convert the memorized banks into points under time pressure. The July 2026 CA
> bar essay session gives **five one-hour essays**. Each is graded on issue-spotting +
> rule + application + organization. The bank does the rule work; exam day is about
> spotting and applying fast.

## The one-hour clock (per essay)

| Phase | Time | What you do |
|-------|------|-------------|
| Read + spot | ~10 min | Read the call(s) first, then facts. Margin-note every issue. Map facts to issues. |
| Outline | ~5 min | Order issues to track the calls. Decide headings. |
| Write | ~40–43 min | Transcribe banked rule blocks; fill the "Here," with these facts; conclude. |
| Review | ~2 min | Headings present? Every call answered? Conclusions stated? |

If you fall behind, **never skip an issue's heading** — a labeled issue with a one-line
rule beats a beautifully written single issue. Graders scan for issue headings.

## IRAC discipline (the scoring engine)

Each issue = the banked block:
- **Issue heading** — underlined/bold label. This is what the grader's checklist matches.
- **Rule** — the memorized statement. Don't improvise law you have banked.
- **Application ("Here,")** — *this is where points live.* Tie each rule element to a
  specific fact and say why it is/isn't met. Argue both sides when the facts are close.
- **Conclusion ("Thus,")** — short, decisive. A naked conclusion with no application is
  the most common point leak.

The application is the differentiator: two examinees state the same rule, but the one who
**uses the facts** ("Here, because Buyer lived in New York with intent to remain, he is a
NY domiciliary") scores higher than "Here, Buyer is a NY citizen."

## Issue-spotting discipline

- **Read the calls first.** Interrogatory-style calls ("Does the court have SMJ?") tell you
  exactly which banked issues to deploy and in what order. Open-ended calls ("What are X's
  rights?") require you to run the full menu from that subject's attack outline.
- **Every fact is there for a reason.** A date → SOL or timeliness. A dollar amount → amount
  in controversy or jurisdiction. A relationship → fiduciary duty, privilege, undue
  influence. Quoted language → a specific element (e.g., "fraud in the supposed value").
- **Run the attack outline mentally** for the identified subject; that's what Part 1 of each
  topic file is for. Tick off each major issue, then its minors.
- **Spot the CA divergence.** The 🔴 flags in the banks are where examiners hide the points —
  flag CEC-vs-FRE, CA community property, CA professional-responsibility, pure comparative
  fault, etc.

## Organization & format

- One issue, one paragraph (or a heading + short paragraph). White space helps the grader.
- Use the call's own language in your headings when it's interrogatory-style.
- Sub-head nested issues (e.g., "Diversity Jurisdiction" → "Citizenship" → "Amount in
  Controversy"), mirroring the bank's hierarchy.
- Don't write a long abstract intro; get to issue one.

## Triage when time is short

1. Make sure **every call is answered** at least skeletally before perfecting any one.
2. Lead each issue with its **rule sentence** (banked) so even a thin application still
   earns the rule points.
3. Spend marginal minutes on **major issues** (the 🟢 anchors) over minor satellites.

## Crossover essays

CA essays frequently combine subjects (Con Law + Crim Pro; Contracts + Remedies; Wills +
Trusts + Community Property; PR layered onto any litigation fact pattern). When you spot a
crossover, deploy both banks and use the cross-reference notes in Part 3 of each file.

## Practice loop (use the Grade mode)

After writing a timed essay, run the skill's **Grade** mode: compare your answer to the
subject's issue bank — which banked major/minor issues did you raise vs. miss? Did each
issue get rule + application + conclusion? Did you catch the CA divergences? Re-drill the
missed issues from the bank before the next attempt.
