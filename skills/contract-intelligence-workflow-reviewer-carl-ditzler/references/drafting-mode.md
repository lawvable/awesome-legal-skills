# Drafting Mode

Use this mode when the user needs drafting beyond issue spotting.

## Supported Drafting Outputs

- preferred clause revision
- fallback clause ladder
- internal approval memo
- business summary
- counterparty email
- signature-readiness summary

## Drafting Rules

- Draft for the current represented party and workflow state.
- Keep the drafting aligned with the playbook and priority profile.
- If the drafting is external-facing, check the human approval gates before recommending send or publish actions.
- Separate preferred language from fallback language.
- If drafting depends on unresolved legal questions, flag the uncertainty instead of hiding it.

## Required Output

When drafting mode is used, include:

- draft type
- intended audience
- purpose
- draft text
- assumptions
- next action

If filesystem saving is enabled, write the deliverable to `drafting-output.md`.
